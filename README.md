# Back to Bed

> Minecraft mod that introduces special items called **Returners** — magical tools that allow you to teleport back to your bed with ease. Whether you're deep in the Overworld, Nether, or End, these Returners help you get home safe and fast.

---

When used, the player must hold right-click (default is 3 seconds) _(configurable)_ to activate the teleportation. Teleportation can be interrupted by releasing the right-click before the time is up.

### Feature
If the player is riding a mount/entity (e.g., horse, boat), the **Magical Returner** will teleport both the player and their mount back to bed.

## **Functionality:**
- **Dimension Restriction:** The teleportation works only in the **Overworld**.
- **Bed Requirement:** If the player's bed is destroyed, teleportation will fail.
- **Cooldown:** After use, the item has a **2.5-second cooldown**. _(configurable)_
- **Crafting:** The recipe unlocks once the player has obtained an **Amethyst Shard**.

## ⚙️ Configuration

You can customize behavior for each returner (or all of them globally) using the config file.

📄 **Config file location:**

- **Forge / NeoForge:** `config/backtobed-common.toml`  
- **Fabric:** `config/backtobed.json`

> ⚠️ **Note:** For **Fabric**, this mod requires the [MidnightLib](https://modrinth.com/mod/midnightlib) library, version **1.5.6** or higher.
